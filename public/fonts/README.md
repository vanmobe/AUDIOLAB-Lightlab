# Bundled typography

Lightlab follows the typography of [Audiolab](https://co-lab.eu/audiolab/): Mulish for the interface and Syncopate Bold for the wordmark. Fonts are served locally; no font CDN or network connection is needed at runtime. System fonts remain the fallback.

- `Mulish.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/mulish), variable weight font; SIL Open Font License in `Mulish-OFL.txt`.
- `Syncopate-Bold.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/apache/syncopate); Apache 2.0 license in `Syncopate-LICENSE.txt`.

Original font files and accompanying licenses retrieved on 2026-09-14. Retain the licenses when distributing the application.
